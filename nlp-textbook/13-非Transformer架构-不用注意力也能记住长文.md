# NLP 读书笔记（13）：非 Transformer 架构——不用注意力，也能记住长文

> 来源：中文 NLP 教材（浙江大学），《Foundations of LLMs》讲义第二章 2.6 节
> 覆盖：书页码 82–96（2.6.1 状态空间模型 SSM、2.6.2 训练时更新 TTT）· 本篇为 clean-room 重写，代码为自写示例并已运行验证

## 一句话核心观点

Transformer 有一笔天生的账：序列越长，注意力要两两打分，计算按长度的平方涨。这一节讲三波挑战者怎么绕开这笔账——**状态空间模型（SSM）把全部历史压进一个会衰减的状态，训练时展开成卷积并行算、推理时退回递归一步步算；RWKV 把这套衰减加权做成能像 Transformer 一样训练、像 RNN 一样推理的混合体；Mamba 再给 SSM 装上"选择性"，让步长和读写都随输入变，该记的使劲记、该忘的轻轻放；TTT 更激进：隐状态干脆不再是一个向量，而是一个在测试时还在被梯度更新的小模型。** 四条路殊途同归：把长序列的成本从平方压回线性，代价是把"全部原文随时可查"换成"压缩过的记忆"。

## 详细解读

### 1. 为什么要找替代品：平方账与长程依赖

先把动机说透。RNN 是线性的：读一个词算一步，成本随长度成正比，但它只能串行训练，而且历史被反复折叠，远处的信息衰减得厉害——长程依赖（Long-Range Dependencies）一直是它的死穴，GRU、LSTM 都是在给这个死穴打补丁。Transformer 反过来：训练能并行、任意两个词一步直达，但注意力矩阵是长度乘长度，序列翻一倍、账翻四倍；生成时还要把全部键值缓存（第 12 篇算过那间仓库）随身带着。教材 2.6 节的立场很清楚：不是 Transformer 不好，而是"有没有一种架构，训练像 Transformer 一样并行、推理像 RNN 一样便宜，还能记住很远的事"——SSM、RWKV、Mamba、TTT 就是沿这条线排出的四代答案。

### 2. SSM：一个从控制论借来的状态方程

状态空间模型不是为语言发明的，它来自描述动态系统的经典框架：一组看不见的内部状态 x(t)，被输入 u(t) 推动着演化，再经输出方程 y(t) 读出来。连续形式只有两行：状态怎么变，x′(t) = A x(t) + B u(t)；输出怎么读，y(t) = C x(t) + D u(t)（实践中 D 常被略去）。A 决定旧状态保留多少、如何互相混合，B 决定新输入往状态里写多少，C 决定最后从状态里读什么出来。把它放进语言模型，u 就是逐个进来的词，x 就是"到目前为止的全部历史的压缩"，y 就是对下一词的预测依据。这和第 03 篇 RNN 的隐状态是同一个思想位置，区别在 SSM 的状态演化是线性的、且有一整套成熟的数学工具伺候它。

进计算机之前要过一道关：离散化。连续方程按步长 Δ 切成一步一步的离散版本，教材用的是双线性（Tustin）近似：Ā = (I − ΔA/2)⁻¹(I + ΔA/2)、B̄ = (I − ΔA/2)⁻¹ΔB、C̄ = C。我的验证代码用标量版算了一遍：A = −0.5、Δ = 0.5 时 Ā ≈ 0.778——每往前走一步，旧记忆先乘上 0.778 再叠加新输入。这个数就是 SSM 的"记性旋钮"：离 1 越近记得越久，离 0 越近忘得越快。离散之后得到的就是熟悉的递归式：x_k = Ā x_{k−1} + B̄ u_k，y_k = C̄ x_k。

### 3. 同一个 SSM 的两副面孔：递归与卷积

SSM 真正漂亮的地方，是把递归式一层层展开之后，它会自己变成一个卷积。第 k 步的输出可以写成此前所有输入的加权和，权重排成一条核：K̄ = (C̄B̄, C̄ĀB̄, …, C̄ĀᵏB̄)，于是 y = K̄ ∗ u。我的代码把两条路都算了：同一个随机输入序列，递归一步步算和卷积一遍算，最大误差 2.2e-16，是浮点误差量级——同一模型、两种算法，分毫不差。这意味着训练和推理可以各取所需：训练时序列全在手里，用卷积（实践中配快速傅里叶变换）一次并行算完；推理时逐个生成，用递归，每步只做常数工作、只带一个状态。RNN 训练串行、Transformer 推理带全量缓存，这两个痛点被一副"双面孔"同时解掉——前提是核要足够长、远处权重不能衰减太快，这就引出了结构化。

裸 SSM 有个老问题：A 矩阵随便初始化，长程记忆根本保不住。教材点到的解法是 S4（结构化状态空间模型）：对 A 做特殊参数化，并用 HiPPO 理论给它一套专门为"记住长历史"设计的初始化——直觉上是让状态按一组精心选的基函数去拟合截至目前的全部输入，而不是随手压缩。这一手之后，SSM 才第一次在长程依赖基准上真正能打。记住这个因果链：SSM 的骨架很老，能打靠的是离散化、卷积等价和 HiPPO 这三件现代装备。

### 4. RWKV：把衰减加权做成一层，像 Transformer 训练、像 RNN 推理

RWKV（Receptance Weighted Key Value）教材归在 SSM 一脉，思路是把注意力的"加权求和"改造成带时间衰减的版本。它的层由两个模块交替：时间混合（Time Mixing）负责跨词传递信息，通道混合（Channel Mixing）负责在特征维度内加工；词进来前还有一个 Token Shift，把上一个位置的向量挪一点过来混入，相当于用最便宜的方式先交换一轮邻里信息。时间混合的核心算子 WKV 值得看公式长相：每个历史词的贡献按 e^{−(t−i)w + k_i} 加权——w 是每个通道自己的衰减率，距离越远指数压得越狠，k 是该词的键、决定它天生有多响，u 是给当前词留的额外话语权。我的玩具版算了一组数：站在第 5 个位置回望，衰减后的归一权重从最旧到最新是 0.088、0.125、0.177、0.252、0.357，四步前那个幅度为 10 的大信号被稀释之后仍留有可见影响，但话语权已经让给了新信息。

这套公式有个关键性质：分子分母都是可累加量。训练时它能展开成并行形式、吃满 GPU（作者为此写了专门的 CUDA 核）；推理时又能折回递归，只维护两个累加器，状态大小恒定、每步成本恒定。教材给的定位很准：RWKV 已扩展到 14B 量级、在多项任务上追近同级 Transformer，同时保有 RNN 式推理的成本结构；短板同样写明——在部分长程任务上仍逊于 S4 这类正统 SSM。它的历史意义不在赢了谁，而在证明了"注意力可以被一种带衰减的线性加权平替"，这条线后来和 Mamba 合流成了一整类线性时序架构。

### 5. Mamba：让 SSM 学会挑食——选择性与硬件感知

经典 SSM 有个先天缺陷：A、B、C、Δ 对所有输入一视同仁。可语言不是均匀的——标点和虚词该轻轻滑过，关键实体该重重记下；一套固定参数没法区别对待，这正是它长期打不过注意力的地方（注意力天生就是输入相关的）。Mamba 的第一手叫选择机制：让 B、C 和步长 Δ 都变成当前输入的函数，B = s_B(x)、C = s_C(x)、Δ 经一层线性投影再过 softplus。Δ 的角色最要紧：它就是第 2 节那个"记性旋钮"的步长——Δ 大，这一步把旧状态冲淡、多写新输入；Δ 小，状态几乎原样保留、新输入轻轻掠过。我的代码用玩具线性层演示了量级差：噪声级输入给出 Δ ≈ 0.13，强信号给出 Δ ≈ 2.58，写入强度差 20 倍。同一条状态通道，从此有了挑食能力。

第二手是硬件感知算法，思想和 FlashAttention 同源：GPU 的显存（HBM）大但慢、片上缓存（SRAM）小但快，瓶颈往往不是算力而是搬运。Mamba 把离散化、扫描、投影尽量融合成少数几个核，在 SRAM 里算完再写回，并用重算换搬运，绕开把庞大的中间状态反复进出显存。教材转述的结果量级：同样 A100 上推理吞吐约为 Transformer 的 5 倍；Mamba-3B 在多项任务上超过同级 Transformer、追近两倍大的模型；且随序列变长优势扩大，因为它的账是线性的。架构图也很简洁：归一化后分两条支路，一路线性投影接一维卷积和 SiLU 激活再进选择性 SSM，另一路做门控，最后汇合输出——没有注意力层，也没有单独的 MLP 块，两件事被揉进了一个模块。

### 6. TTT：隐状态升级成一个还在学习的小模型

2.6.2 节的 TTT（Test-Time Training，测试时训练）把思路再推一格。教材的出发点是：哪怕 Mamba，在 16k 以上长度仍会吃力（原文引述的研究口径）——因为无论状态向量做得多巧，它终究是固定维度的压缩，长文总有塞爆的一天。TTT 的解法是换隐状态的物种：隐状态不再是向量，而是一组权重 W，本身就是一个小模型 f。读入新词 x_t 时分三步：先用自监督任务算损失，ℓ(W_{t−1}; x_t) = ‖f(θ_K x_t; W_{t−1}) − θ_V x_t‖²，即"用一种变换后的视图去预测另一种视图"，不需要任何外部标签；再做一步梯度更新 W_t = W_{t−1} − η∇ℓ；最后用更新后的模型产出这一位的表示 z_t = f(x_t; W_t)。我的玩具代码完整跑了这个回路：五步之内 W 从 0 一路爬向真值 1.875，每步都是更新后损失低于更新前——模型是一边读、一边把刚读的东西学进去的。

表达能力是这套设计的核心卖点：一个向量的容量随维度线性增长，而一个小模型的容量可以非线性地组织信息，理论上能装下复杂得多的长程结构；代价也明摆着——每步都要算梯度，单步成本远高于一次矩阵乘，且"内层学什么任务"本身需要设计。教材把它与 SSM 并列为长序列的两条前沿路线，一个改状态的动力学，一个改状态的本体。联系第 08 篇的三种架构看，这条线其实绕回了 RNN 的原点：都是"状态随输入演化"，只是状态从向量变成了参数，演化从矩阵乘变成了梯度下降。

### 7. 四条路线的账本

| 路线 | 隐状态是什么 | 训练 | 推理每步 | 长程机制 |
|---|---|---|---|---|
| Transformer | 全部键值缓存 | 并行，O(n²) | 带全量缓存 | 任意两词直达 |
| SSM / S4 | 固定维状态向量 | 卷积并行 | O(1) 递归 | HiPPO 初始化保长记忆 |
| RWKV | 两个衰减累加量 | 并行（专用核） | O(1) 递归 | 指数衰减加权 |
| Mamba | 固定维状态向量 | 并行扫描 | O(1) 递归 | 选择性：Δ/B/C 随输入变 |
| TTT | 一个小模型的权重 | 逐位梯度更新 | 一步梯度更新 | 状态本身能"学习" |

一行总结：这一节不是"谁取代谁"的故事，而是把 Transformer 的全量记忆拆开定价之后，不同路线在不同价位上的取舍。下一篇进入第三章 Prompt 工程——架构之争暂告段落，问题换成：模型已经训好了，不动一个参数，怎么把它的本事榨出来。

## 代码验证（已运行）

自写脚本 `13-ssm-verify.py`（numpy 加标准库，手写，无教材代码，固定随机种子可复现），做了六件事：标量 SSM 的双线性离散化；递归与卷积两种算法的等价验证；注意力平方复杂度与 SSM 线性复杂度的对照账；RWKV 式指数衰减加权的玩具演示；Mamba 选择性步长（softplus 后的 Δ 随输入强度变化）；TTT 一步梯度更新的完整玩具回路。

```python
# 离散化 (标量版): A_bar = (1 + Delta*A/2) / (1 - Delta*A/2)
A_bar = (1 + Delta * A / 2) / (1 - Delta * A / 2)   # A=-0.5, Delta=0.5 -> 0.7778

# 卷积核: K_k = C * A_bar**k * B_bar, 递归与卷积结果误差 ~1e-16
K = np.array([C_bar * (A_bar ** k) * B_bar for k in range(len(u))])
y_conv = np.convolve(u, K)[: len(u)]

# TTT: 每读一个新输入, 先按自监督损失做一步梯度更新再产出
W = W - eta * grad   # 五步内 W: 0 -> 1.395, 真值 1.875, 每步损失都下降
```

## 我的思考/应用

- **给长文档任务选模型时，"上下文多长"要追问第二层：是全量缓存还是压缩状态。** Transformer 的长上下文是把原文全带着，引用定位准，但按平方或缓存账收费；SSM 类是压缩记忆，便宜、能塞更长，但远处细节是衰减过的。我的实际分工照此定：要逐字核对、查引用出处的（校对、合同、讲章核查）只用全量上下文路线；要通读大意、做结构提炼的（网盘长文档提炼大纲）可以放心用便宜的长上下文方案，前提是提炼后关键事实再回原文抽查。（成本：0，选型纪律；收益：长文档任务的成本与翻车率同时下降；证据 B，架构性质为教材结论，任务映射为经验判断）
- **Mamba 的选择性 Δ，是给我自己的上下文管理立的规矩。** 同一条状态通道，对强信号大步写入、对噪声小步掠过——我给模型喂上下文时该做同样的事：与本步决策强相关的材料给全文，背景材料给摘要，无关材料不进。上下文不是越满越好，塞满噪声等于把 Δ 在垃圾上开大。（成本：喂料前多一步分级，约数分钟；收益：有效信号占比上升，幻觉与跑题随之下降；证据 C，方法迁移，选择性机制本身为 A 级论文结论）
- **TTT 的"现读现学"提示我：长会话里要主动维护一份滚动状态，而不是指望模型记住。** TTT 把记忆做成可持续更新的权重，我的对应物是每条长线的状态文件：进度、口径、卡点随做随更新，新会话先读状态再干活。这和把全部聊天记录回放给模型相比，就是递归状态对全量缓存——便宜，且不会被噪声稀释。本拆书流水线的进度正是这么记的（仓库文件清单即状态），继续坚持。（成本：每条线维护状态文件数分钟/天；收益：跨会话不丢口径、不重复劳动；证据 B，与本系统运行实测互证）
- **复杂度账要进采购与排产：能线性的地方不付平方的钱。** 批量处理长文本（几百篇讲章、整仓笔记）时，单篇长度和调用次数决定账本形状；同样质量下优先选线性成本的路径（先提炼压缩、再对短文本做精细处理），把贵的精细算力留给终审环节。这条与第 12 篇的推理账是同一本账的续篇。（成本：0，排产口径；收益：批量线额度消耗可预测，不易撞限额；证据 A，复杂度公式可算、已实测演示）
- **架构多元化本身是选型保险。** 开源生态里 Mamba、RWKV 类模型已可本地部署，处理超长日志、整本电子书这类"长而糙"的材料时是现成的省钱选项；不必现在就部署，但选型清单里要留这一栏，等某条线的长度成本真成为瓶颈时直接取用，不临时调研。（成本：0，清单维护；收益：瓶颈出现时切换路径现成；证据 C，前瞻判断，模型可用性为 B 级公开事实）

4. 挑食动画：词流里飞过标点和虚词，光球几乎不变色；一个关键人名飞入，光球猛地一亮、颜色大改——"Mamba 的绝招叫选择性：该记的使劲记，该忘的轻轻放。"
