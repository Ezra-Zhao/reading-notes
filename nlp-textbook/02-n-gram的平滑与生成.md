## 一句话核心观点

n-gram 最大的敌人是"没见过"——语料库里没出现过的搭配，概率会被算成零；平滑就是给"没见过"留一条活路。而"只看前 n-1 个词"这个偷懒的假设，恰恰让机器第一次学会了"写"句子。

## 详细解读

### 1. 零概率问题：没见过 = 不可能吗？

假设用 trigram 算某个三元搭配的概率，分子是这个三元组在语料库里的出现次数。如果它一次都没出现过，概率就是 0。整句话的概率是连乘，一个 0 会把整句话"枪毙"掉。

这显然不合理：**语料库没收录 ≠ 现实中不可能**。语料库再大，也覆盖不了所有搭配。n 越大，这个问题越严重——trigram 的零概率比 bigram 多得多。

### 2. 平滑（Smoothing）：给没见过的留活路

平滑的核心思想就一句话：**从见过的搭配手里"抠"一点概率，分给没见过的搭配**。

最直观的是"加一平滑"（Add-One / Laplace Smoothing）：每个计数都先加 1。

P(wi | wi-1) = (C(wi-1, wi) + 1) / (C(wi-1) + V)

其中 V 是词表大小。这样即使 C(wi-1, wi) = 0，概率也是 1/(C(wi-1)+V)，一个很小的正数，而不是 0。代价是：见过的搭配概率会被稍微"稀释"。更精细的做法还有加 k 平滑、回退（back-off）、插值等，但思想都一样——**别把概率押成 0**。

### 3. 文本生成：机器第一次"写"句子

n-gram 不只能打分，还能生成。做法：

1. 给定开头 n-1 个词；
2. 查表得到"下一个词"的概率分布；
3. 按概率采样（或取最大）一个词，接上去；
4. 重复，直到生成足够长。

背后的假设叫**马尔可夫假设**：

P(wN | w1…wN-1) ≈ P(wN | wN-n+1…wN-1)

即"下一个词只跟最近的 n-1 个词有关，更早的历史不看"。这是个很强的简化——但正是这个简化，让生成在计算上变得可行。n 越大，生成的句子越连贯、越像人话，但也越容易"背诵"语料库原文。

### 4. 深一层：为什么"数数"就是最优解？（极大似然估计）

书里用一节篇幅证明了一件事：**数数法不是拍脑袋，它是极大似然估计（MLE）的数学最优解**。

思路是这样的：把每个条件概率 P(wj|wi) 当成待求参数 θ，写出语料库的似然函数 L(θ)——也就是"在这组参数下，整个语料库出现的概率"。然后求让 L(θ) 最大的参数。

因为概率要满足"给定 wi，后面所有可能词的概率和为 1"的约束，求解时引入拉格朗日乘子，对 L(θ) 求导并令导数为 0，解出来恰好就是：

P(wj | wi) = C(wi, wj) / C(wi)

——正是我们手算的那个"数数公式"。**直觉上最自然的做法，数学上也是最优的**，这是 n-gram 漂亮的地方。这个结论可以推广到 n > 2 的情形。

### 5. 手写代码：加一平滑 + 自动生成句子

```python
from collections import Counter
import random

# 自写迷你语料（与上一篇同一套，方便对照）
corpus = [
    "小猫 爱 吃 鱼",
    "小猫 爱 睡觉",
    "小狗 爱 吃 骨头",
    "小狗 爱 跑步",
    "小猫 不 爱 洗澡",
]

def train(corpus):
    bc, uc, vocab = Counter(), Counter(), set()
    for sent in corpus:
        words = sent.split()
        vocab.update(words)
        for w in words:
            uc[w] += 1
        for a, b in zip(words, words[1:]):
            bc[(a, b)] += 1
    return bc, uc, vocab

bc, uc, vocab = train(corpus)
V = len(vocab)

def prob_smooth(prev, word, k=1.0):
    # 加 k 平滑：P(word|prev) = (C(prev,word)+k) / (C(prev)+k*V)
    return (bc[(prev, word)] + k) / (uc[prev] + k * V)

# 对比：没见过的搭配 "睡觉 -> 鱼"
print("不平滑:", bc[("睡觉", "鱼")] / uc["睡觉"] if uc["睡觉"] else 0)  # 0.0
print("平滑后:", round(prob_smooth("睡觉", "鱼"), 4))                  # 小正数，不再是 0

def generate(start, length=8, k=1.0, seed=42):
    random.seed(seed)
    words = start.split()
    vocab_list = sorted(vocab)
    while len(words) < length:
        prev = words[-1]
        # 按平滑后的概率分布采样下一个词
        probs = [prob_smooth(prev, w, k) for w in vocab_list]
        words.append(random.choices(vocab_list, weights=probs)[0])
    return " ".join(words)

print(generate("小猫", length=8))  # 如：小猫 爱 吃 鱼 ...（每次采样可能不同）
```

注意 `generate("小猫")` 的输出：它大概率生成"小猫 爱 吃 鱼"这类见过的搭配，偶尔冒出没见过的组合——**这就是最原始的"AI 写作"**：查表 + 掷骰子。

## 我的思考/应用

1. **平滑的哲学 = 对未知的谦卑**：模型承认"世界比我的语料库大"。今天大模型的 temperature 采样、top-p 截断，骨子里是同一种思想——别把概率押死。
2. **n 越大越像"背书"**：n=5 的模型生成的句子常常是语料库原文的拼接。这解释了为什么大模型有时会"背诵"训练数据——上下文窗口越长，记忆性越强。
3. **MLE 这座桥**：从"数数"到"拉格朗日乘子"，书里把直觉和数学连起来了。后面学神经网络语言模型时，训练目标（交叉熵）本质上还是 MLE——这一节是地基。
