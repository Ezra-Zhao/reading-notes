## 2026-11-16 · Market Wizards（38）：Trout——先把回撤写成三道闸的人

- [ ] 开场钩子：五年平均赚 67%，最大回撤却只有 8% 出头。同一个人退休时，全程账只有年均 21.5%——哪一个才是真的？今天讲 Monroe Trout，先把两本账分开。
