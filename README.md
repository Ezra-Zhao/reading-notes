## 2026-11-15 · Market Wizards（25）：葛兰——把全部身家压在一个行业里的人

- [ ] 开场钩子：全市场最懂医药的基金经理之一，清华读完去美国读生物医学工程博士，回国只管医药基金——十年之后，她的账说明了一件什么事？今天讲葛兰。
- [ ] 算账段：白板三行——2020 年 +98.85%、2021 年 -6.55%、2022 年 -23.29%，连乘 +42.55%，和年报自报的 42.54% 对得上。旁白：先对账，再讲故事。
- [ ] 规模段：白板画两级台阶——医疗健康 232 亿、775 亿、再落到 255 亿；在管总规模 906 亿落到 333 亿。旁白：钱是在涨完之后涌进来的，也是从高点一路走的。
- [ ] 百分比段：白板写 66,488.88%——划掉，改写基数 1.8 万股。旁白：百分比大到五位数时，先看基数，再看动作。
- [ ] 收尾金句：专业对口能让你看懂一个行业，却不能让合同带你离开这个行业。下一篇回海外组。

## 2026-11-15 · Market Wizards（26）：Ryan——先把错题本翻完，再去拿冠军

- [ ] 开场钩子：他 13 岁买了第一只股票，买的是自己天天吃的糖果公司。十年后，他愿意免费打工，只为进偶像的公司。今天讲 David Ryan。
- [ ] 先亏后翻段：白板三行——20,000 美元、52,000 美元、16,000 美元。旁白：冠军的起点不是第一行，是第三行；从高点跌了约 69%，他坐下来把每一笔错误翻完。
- [ ] 对账段：白板写 161%、160%、约 118%，连乘 14.79 倍。旁白：流传的三连冠和 155% 都对不上原文与连乘——传奇先对账，再惊叹。
- [ ] 买点段：动画一条线——50 美元突破、55 美元追高，同一条 48 美元退出线，风险从 4.0% 变成约 12.73%。旁白：公司没变，买晚了，风险自己涨了三倍多。
- [ ] 收尾金句：他每周看约 4,000 张图，但最值钱的习惯是每买一只都写下理由。下一篇回中国组——继续守身份门，找下一位身份能被公开文件证实的人。

## 2026-11-15 · Market Wizards（27）：谢治宇——先涨四成，再跌两成半

- [ ] 开场钩子：他的标签是公募里最稳、最均衡的那一类。可 2026 年，他的基金一个季度涨了 41%，下一个季度又跌了 25%。今天讲谢治宇。
- [ ] 连乘段：白板写三行——+41.18%、-24.97%、半年只剩 +5.92%。旁白：两个大数字连乘完，和季报自报的半年收益分毫不差。先对账，再惊叹。
- [ ] 回本段：白板写 -24.97%，箭头反过来标 +33.28%。旁白：跌四分之一，回本要涨三分之一。跌幅和回本价，从来不是同一个数。
- [ ] 份额段：动画天平——一边是 61 亿元的单季亏损，一边是只走了 1.42% 的份额。旁白：这一季规模是跌没的，不是跑没的。两种缩水，两种病。
- [ ] 收尾金句：均衡是他写在招募书里的意图，+41% 和 -25% 是净值给出的结果。下一篇回海外组。

## 2026-11-15 · Market Wizards（28）：Blake——一百三十九个月，只亏五个月

- [ ] 开场钩子：139 个月，只亏 5 个月，最差的一年还赚了 24%。他不在交易大厅上班，他在图书馆上班。今天讲 Gil Blake。
- [ ] 一分钱规则段：动画一张净值表连跌约 22 天，旁边标出 83%。旁白：第二天同方向的概率约 83%——规律小到只有一分钱，他却先拿两年数据把它算到信服。
- [ ] 硬币段：动画抛 1 枚、9 枚、99 枚硬币，正面概率 55%、62%、84%。旁白：原书说 99 枚是约 75%，复算其实是约 84%——原书把自己的道理还算小了。先验算，再引用。
- [ ] 灯板段：动画一排板块灯，红绿交替，只取最亮的绿灯，全红就回现金。旁白：全仓、只做一个板块、持有一到四天——集中是他的打法，24 小时过不去就减仓是他的上限。
- [ ] 收尾金句：破一次纪律，下一次就容易得多。他记违规能记好几年。下一篇回中国组——继续守身份门，找下一位身份能被公开文件证实的人。

## 2026-11-15 · Market Wizards（29）：傅鹏博——跌下来，反而把仓位加上去的人

- [ ] 开场钩子：同一只基金，五年只涨 29%，一年却涨 116%——这两个数怎么能同时是真的？今天讲傅鹏博，先做一道除法。
- [ ] 除法段：白板写 1.2914 除以 2.1581，等于先跌约 40%。旁白：长期收益的形状是深坑加陡坡，不是直线。
- [ ] 份额段：动画一边净值单季 +45.79% 往上冲，一边份额净赎回约 15.59% 往下走。旁白：涨得最猛的季度，约一成半的人下了车。
- [ ] 仓位段：白板写 222.01 亿、157.19 亿、88.73%、91.17%。旁白：资产缩了三成，仓位反而加了——跌的时候加仓，是他写在动作里的回答。
- [ ] 收尾金句：读季报先对表格，再读观点；看经理先看跌时仓位，再听涨时说法。下一篇回海外组。

## 2026-11-15 · Market Wizards（30）：Eckhardt——说自己从没打过那个赌的人

- [ ] 开场钩子：流传四十年的故事说，他打赌输了——他说交易教不会，结果一群新手赚了上亿美元。四十年后，他第一次上播客，第一句话是：我从没说过那句话。今天讲 William Eckhardt。
- [ ] 纠错段：动画两个人对坐，白板一边写「能不能教」，划掉；改写「能不能轻易机械化」。旁白：他们真正吵的不是天赋，是把交易写成规则到底有多难；海龟是 Dennis 的项目，风险是 Dennis 定的，他只出系统、当顾问。
- [ ] 三十四年账段：白板写 410 个月、9.35%、−27.11%。旁白：没有传奇增速，只有一张能逐月查的表——盈利的月份只占 54.63%，最深的一跤跌在开始后的第一年。
- [ ] 规模段：白板写三个数——10 亿、2 亿、9,420 万，逐个标上年份与口径。旁白：三个数都对，错的是不问时点就引用。
- [ ] 收尾金句：多数人先找赚钱的方法，再补风险；他先把风险写成数学，再谈赚钱。五十年过去，他还在改系统——机械化做成了，靠的不是写死，是不停地验。下一篇回中国组——继续守身份门，找下一位身份能被公开文件证实的人。

## 2026-11-15 · Market Wizards（31）：丘栋荣——一个人管了全公司四分之三的钱

- [ ] 开场钩子：一家基金公司六只产品，他一个人管了五只、占全公司 77.52% 的钱。2024 年 7 月他走了，不到两年，公司规模少了一半。今天讲丘栋荣。
- [ ] 两段账段：白板两行——汇丰晋信大盘 +193.86%、中庚价值领航 +121.07%。旁白：第一段是在暴跌和熔断里拿的，第二段是五年七个月、从 1 元做到 2.2107 元拿的。先对账，再惊叹。
- [ ] 赎回段：白板写 39.02 亿份、12.40 亿份，箭头标 −68.22%。旁白：2024 年这只基金的净值是涨的，钱却是被人拿走的——份额先看，再看净值。
- [ ] 股东段：白板写 9.73%，旁边写「经理走了，股东还在」。旁白：他卸的是经理和副总，留的是股东——这篇故事的结尾不在离任公告上，在股东名单上。
- [ ] 收尾金句：低估值能帮你找到便宜的公司，帮不了你留住要走的钱；一家公司把四分之三押在一个人身上时，最大的风险从来不是市场。下一篇回海外组。
