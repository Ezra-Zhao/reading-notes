## 2026-11-15 · Market Wizards（25）：葛兰——把全部身家压在一个行业里的人

- [ ] 开场钩子：全市场最懂医药的基金经理之一，清华读完去美国读生物医学工程博士，回国只管医药基金——十年之后，她的账说明了一件什么事？今天讲葛兰。
- [ ] 算账段：白板三行——2020 年 +98.85%、2021 年 -6.55%、2022 年 -23.29%，连乘 +42.55%，和年报自报的 42.54% 对得上。旁白：先对账，再讲故事。
- [ ] 规模段：白板画两级台阶——医疗健康 232 亿、775 亿、再落到 255 亿；在管总规模 906 亿落到 333 亿。旁白：钱是在涨完之后涌进来的，也是从高点一路走的。
- [ ] 百分比段：白板写 66,488.88%——划掉，改写基数 1.8 万股。旁白：百分比大到五位数时，先看基数，再看动作。
- [ ] 收尾金句：专业对口能让你看懂一个行业，却不能让合同带你离开这个行业。下一篇回海外组。

## 2026-11-15 · Market Wizards（26）：Ryan——先把错题本翻完，再去拿冠军

- [ ] 开场钩子：他 13 岁买了第一只股票，买的是自己天天吃的糖果公司。十年后，他愿意免费打工，只为进偶像的公司。今天讲 David Ryan。
- [ ] 先亏后翻段：白板三行——20,000 美元、52,000 美元、16,000 美元。旁白：冠军的起点不是第一行，是第三行；从高点跌了约 69%，他坐下来把每一笔错误翻完。
- [ ] 对账段：白板写 161%、160%、约 118%，连乘 14.79 倍。旁白：流传的三连冠和 155% 都对不上原文与连乘——传奇先对账，再惊叹。
- [ ] 买点段：动画一条线——50 美元突破、55 美元追高，同一条 48 美元退出线，风险从 4.0% 变成约 12.73%。旁白：公司没变，买晚了，风险自己涨了三倍多。
- [ ] 收尾金句：他每周看约 4,000 张图，但最值钱的习惯是每买一只都写下理由。下一篇回中国组——继续守身份门，找下一位身份能被公开文件证实的人。

## 2026-11-15 · Market Wizards（27）：谢治宇——先涨四成，再跌两成半

- [ ] 开场钩子：他的标签是公募里最稳、最均衡的那一类。可 2026 年，他的基金一个季度涨了 41%，下一个季度又跌了 25%。今天讲谢治宇。
- [ ] 连乘段：白板写三行——+41.18%、-24.97%、半年只剩 +5.92%。旁白：两个大数字连乘完，和季报自报的半年收益分毫不差。先对账，再惊叹。
- [ ] 回本段：白板写 -24.97%，箭头反过来标 +33.28%。旁白：跌四分之一，回本要涨三分之一。跌幅和回本价，从来不是同一个数。
- [ ] 份额段：动画天平——一边是 61 亿元的单季亏损，一边是只走了 1.42% 的份额。旁白：这一季规模是跌没的，不是跑没的。两种缩水，两种病。
- [ ] 收尾金句：均衡是他写在招募书里的意图，+41% 和 -25% 是净值给出的结果。下一篇回海外组。
