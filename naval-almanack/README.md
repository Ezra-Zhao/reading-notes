# 《纳瓦尔宝典》拆书（The Almanack of Naval Ravikant）

Eric Jorgenson 编、Naval Ravikant 口述与推文汇编（Harper Business 2020）。源文件为官网 navalmanack.com 官方免费 PDF（242 页，作者声明公益免费、Naval 本人不从此书获利），2026-10-28 存入本地队列，为拆书主队列第 1 本（Personal MBA、NLP 教材、Nasdaq 指南之后续接）。

全书结构：第一部分「财富」（创造财富＋建立判断力）、第二部分「幸福」（学习幸福＋拯救自己＋哲学）、附录（推荐书单与 Naval 写作）。拆法沿用本仓标准：clean-room 重写、每篇含一句话核心观点＋详细解读＋我的思考/应用＋视频脚本要点；原书无代码，可算的命题自写脚本验证；观点类内容按证据等级如实标注（多为 C 级经验口径）。
